### 🚀 Featured Projects

**[FaceVault](https://github.com/codewithhanzlah/FaceVault-CNN-Biometric-Banking)** — CNN-Powered Biometric Banking Authentication System
- Built an end-to-end facial recognition pipeline using **PyTorch** and a fine-tuned **ResNet18** architecture, with **MTCNN** for face detection and alignment before inference.
- Integrated **OpenCV** and **WebRTC** for real-time webcam capture, then deployed the trained model behind a **Flask** API to simulate secure biometric login for a banking use case.
- Served as the capstone deep learning project for the AKTI AI training program.

**[GradeIQ](https://github.com/codewithhanzlah/GradeIQ-Student-Performance-Predictor)** — Machine Learning Student Performance Predictor
- Designed a full ML pipeline in Python — data cleaning and feature engineering with **Pandas**, model training with **Scikit-learn's Gradient Boosting**, and evaluation using cross-validated accuracy and F1 metrics.
- Wrapped the trained model in a **Flask** web app so predictions on new student data could be generated and reviewed through a simple UI, with the full pipeline tracked and versioned in **Git**.

**[Laptop Analyzer](https://github.com/codewithhanzlah/laptop-analyzer)** — AI-Assisted Hardware Intelligence Tool
- Built a diagnostic tool using **psutil** to pull live hardware telemetry (CPU, RAM, disk, battery health) and **Plotly.js** to visualize it, with **ReportLab** generating exportable PDF health reports.
- Integrated the **Claude API** as an in-app assistant to explain diagnostic results in plain language and suggest next steps, served through a **Flask** backend.

> More projects — including my next capstone combining computer vision with **NLP/LLMs (RAG-based systems)** — are actively in progress. 🚧
